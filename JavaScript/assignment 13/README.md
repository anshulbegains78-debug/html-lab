# Assignment 13: Reduce, Some, Every and Map

## Aim
To understand and use JavaScript array methods such as reduce(), some(), every(), and map().

## Theory

### 1. reduce() Method
The reduce() method processes all elements of an array and reduces them to a single value.

It is commonly used for calculating totals, sums, and other combined results.

### 2. some() Method
The some() method checks whether at least one element in an array satisfies a given condition.

It returns true if any element matches the condition; otherwise, it returns false.

### 3. every() Method
The every() method checks whether all elements in an array satisfy a given condition.

It returns true only when every element passes the condition.

### 4. map() Method
The map() method creates a new array by applying a function to every element of the original array.

It does not directly modify the original array.

## Tasks
1. Use the reduce() method to calculate the total price of items in an array containing 120, 45 and 300. Start the calculation from 0 and print the total.
2. Use some() to check whether any student has marks below 40 and every() to check whether all students have marks of at least 35. Use marks 72, 85, 30 and 90.
3. Use the map() method to add 5 marks to every element of an array containing 72, 85, 64 and 90. Print both the new and original arrays.

## Conclusion
This assignment demonstrates how JavaScript array methods simplify data processing, condition checking, and transformation of array elements.
