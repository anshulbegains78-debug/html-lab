# Assignment 05: Arrays, Array Methods and Nested Arrays

## Aim
To understand arrays in JavaScript, access array elements, use forEach() and filter(), and work with nested arrays.

## Theory

### 1. Arrays in JavaScript
An array is a data structure used to store multiple values in a single variable. Array elements are stored in an ordered manner and accessed using index numbers.

Array indexing starts from 0.

For example:
let marks = [72, 85, 64, 90];

### 2. Array Length
The length property is used to find the total number of elements present in an array.

For example:
marks.length

### 3. forEach() Method
The forEach() method executes a given function once for every element in an array. It is commonly used to display or process array elements.

### 4. filter() Method
The filter() method creates a new array containing only those elements that satisfy a specified condition.

### 5. Nested Arrays
A nested array is an array that contains one or more arrays as its elements. It is useful for representing data in rows and columns.

## Tasks
1. Create an array named marks containing 72, 85, 64 and 90. Print the number of items and the first mark.
2. Store Maths, Science and English in an array and use forEach() to print each subject.
3. Store marks 72, 85, 45 and 90 in an array. Use filter() to create a new array containing only marks of 60 or more and print the new array.
4. Store the arrays [1, 2, 3] and [4, 5, 6] inside another array named grid. Print the number in row 2 and column 3.

## Conclusion
This assignment explains how JavaScript arrays store multiple values and how array methods such as forEach() and filter() make data processing easier. It also introduces nested arrays for storing structured information.
