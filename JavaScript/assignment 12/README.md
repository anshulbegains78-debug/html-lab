# Assignment 12: Callbacks and Higher-Order Functions

## Aim
To understand callback functions and higher-order functions in JavaScript.

## Theory

### 1. Callback Functions
A callback is a function passed as an argument to another function. It is called or executed inside that function.

Callbacks help in creating flexible and reusable code.

### 2. Higher-Order Functions
A higher-order function is a function that accepts another function as an argument or returns a function as its result.

### 3. Arrow Functions
Arrow functions provide a shorter syntax for writing functions in JavaScript.

For example:
const add = (a, b) => a + b;

### 4. Reusing Functions
Callbacks allow the same function to perform different operations depending on the function passed to it.

## Tasks
1. Create an applyTwice() function that accepts another function and a value. Use an addTen() function to perform the operation twice.
2. Create a formatMarks() function that accepts marks and a callback. Use an arrow function to format the marks.
3. Create a repeatAction() function that executes a callback a specified number of times and displays the round number.

## Conclusion
This assignment demonstrates how callbacks and higher-order functions make JavaScript programs more reusable, flexible, and easier to manage.
