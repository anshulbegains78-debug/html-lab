# Assignment 03: Conditions and Loops

## Aim
To understand conditional statements and looping structures in JavaScript using if, else if, else, for loop, and while loop.

## Theory

### 1. Conditional Statements
Conditional statements are used to execute different blocks of code depending on whether a condition is true or false.

JavaScript provides:
- if: Executes code when a condition is true.
- else if: Checks another condition when the previous condition is false.
- else: Executes code when all previous conditions are false.

### 2. Comparison Operators
Comparison operators are used to compare two values.

Examples:
- > : Greater than
- < : Less than
- >= : Greater than or equal to
- <= : Less than or equal to
- == : Equal to
- === : Strict equality

### 3. For Loop
A for loop is used to execute a block of code repeatedly for a specified number of times.

It generally contains initialization, condition, and increment or decrement.

### 4. While Loop
A while loop repeatedly executes a block of code as long as the given condition remains true.

It is useful when the number of repetitions is not fixed in advance.

## Tasks
1. Create a program that stores marks 72 in a variable and prints Grade A when marks are 75 or more, Grade B when marks are 60 or more, and Grade C otherwise.
2. Use a for loop to print numbers from 1 to 5, one on each line.
3. Use a while loop to add 1, then 2, then 3 and so on to a total until the total is more than 20, then print the total.

## Conclusion
This assignment explains how conditional statements make decisions in a program and how loops help execute repeated instructions efficiently.
