# Assignment 04: Divs, Attributes and a Small Fix

## Aim
To understand how to group webpage content using div elements, use HTML attributes and correct errors in an HTML document.

## Theory

### 1. Div Element
The <div> element is a container used to group HTML elements together. It helps organize different sections of a webpage.

### 2. Class Attribute
The class attribute is used to assign a common name to one or more HTML elements. It is commonly used to apply CSS styles to multiple elements.

### 3. ID Attribute
The id attribute gives a unique identity to an HTML element. It can be used to identify a particular element on a webpage.

### 4. Data Attributes
Custom data attributes begin with data- and are used to store additional information in HTML elements.

For example:
`data-topic="hobbies"`

### 5. HTML Error Correction
HTML elements should have correctly written opening and closing tags. Missing closing tags and incorrect element nesting can affect webpage structure.

## Tasks
1. Create layout.html with three div blocks having the classes header, main and footer. Add some text inside each block.
2. Create attributes.html with a div having the id profile. Inside it, add a paragraph with the attribute data-topic set to hobbies.
3. Correct all errors in the given attendance HTML page and save the corrected file as attendance-fixed.html. The page should display the heading Attendance Report and two paragraphs: Asha: 92% and Rohan: 85%.

## Conclusion
This assignment explains how div elements organize webpage content and how class, id and data attributes provide additional information to HTML elements. It also develops the ability to identify and correct HTML errors.
