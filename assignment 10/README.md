# Assignment 10: CSS Fundamentals

## Aim
To understand the different ways of applying CSS to HTML documents and learn how to use CSS selectors and text styling properties.

## Theory

### 1. Introduction to CSS
CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML webpages.

### 2. Inline CSS
Inline CSS is written directly inside the style attribute of an HTML element. It applies styling to that particular element.

### 3. Internal CSS
Internal CSS is written inside a style element in the head section of an HTML document. It can style multiple elements on the same page.

### 4. External CSS
External CSS is written in a separate .css file and connected to an HTML document using the link element.

### 5. CSS Selectors
Selectors are used to target HTML elements for styling.

Common selectors include:
- Element selector: Targets elements such as h1 and p.
- Class selector: Targets elements using a class name.
- ID selector: Targets an element using its unique id.

### 6. CSS Text Properties
CSS provides properties to change text appearance:
- color: Changes text colour.
- font-size: Changes text size.
- font-style: Controls italic styling.
- text-decoration: Adds underline or other text decoration.

## Conclusion
This assignment explains the three methods of applying CSS: inline, internal and external. It also demonstrates how selectors and text styling properties control the appearance of HTML elements.
