# Assignment 05: Links and Images

## Aim
To understand how to create hyperlinks between HTML pages and insert images with suitable alternative text.

## Theory

### 1. Anchor Element
The <a> element is used to create hyperlinks in HTML. It allows users to navigate from one webpage to another.

### 2. href Attribute
The href attribute specifies the destination of a hyperlink.

For example:
`<a href="portfolio.html">portfolio</a>`

### 3. Linking Webpages
Two or more HTML pages can be connected using anchor elements. This helps users navigate between different sections of a website.

### 4. Image Element
The <img> element is used to display images on a webpage. It is an empty element and does not require a closing tag.

### 5. src and alt Attributes
- src: Specifies the image file location.
- alt: Provides alternative text describing the image.

### 6. Image Dimensions
The width and height attributes can be used to specify image dimensions.

## Tasks
1. Create home.html with the heading Welcome to My Site and a paragraph containing a link to portfolio.html. The link text should be portfolio.
2. Create portfolio.html with a heading and a link that takes the user back to home.html.
3. Create portfolio-image.html with a heading and a picture from the images folder. Set its width and height to 200 each and provide descriptive alt text. Use the image filename given by your instructor.

## Conclusion
This assignment explains how HTML links connect different webpages and how images can be inserted using the img element. It also demonstrates the importance of image dimensions and alternative text.
