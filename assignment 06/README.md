# Assignment 06: Types of HTML Lists

## Aim
To understand different types of HTML lists and learn how to create unordered lists, ordered lists, nested lists and description lists.

## Theory

### 1. Unordered List
The <ul> element creates an unordered list. Its items are generally displayed with bullet points.

### 2. Ordered List
The <ol> element creates an ordered list. Its items are displayed with numbers or other sequence markers.

### 3. List Item
The <li> element defines an individual item inside an ordered or unordered list.

### 4. Nested Lists
A nested list is a list placed inside another list item. It is used to represent sub-items under a main item.

### 5. Description List
A description list is used to display terms and their descriptions.

It uses:
- <dl>: Defines the description list.
- <dt>: Defines the term or question.
- <dd>: Defines the description or answer.

## Tasks
1. Create shopping-list.html with the heading Shopping List and an unordered list containing Notebook, Pen and Bag.
2. Create canteen-menu.html with the heading Canteen Menu and an ordered list containing Samosa and Sandwich. Under Sandwich, add a nested ordered list containing Cheese and Vegetable.
3. Create faq.html with a description list containing two questions: How many books can I borrow? and Is the library open on Sunday? Add an answer for each question using dd elements.

## Conclusion
This assignment explains how different HTML list elements organize information. It demonstrates unordered lists, ordered lists, nested lists and description lists.
