# Assignment 07: About Me Page

## Aim
To create a personal About Me webpage using semantic HTML elements, navigation links, sections and a contact link.

## Theory

### 1. Semantic HTML
Semantic HTML elements clearly describe the meaning and purpose of webpage content. They help organize a webpage and make it easier to understand.

### 2. Header Element
The <header> element represents the introductory section of a webpage. It can contain a heading, logo or navigation menu.

### 3. Navigation Element
The <nav> element is used to define a section containing navigation links.

### 4. Main Element
The <main> element represents the main content of a webpage. It contains the central information of the document.

### 5. Section Element
The <section> element groups related content into a meaningful section.

### 6. Footer Element
The <footer> element represents the bottom section of a webpage. It can contain contact details and other additional information.

### 7. Mailto Link
The mailto: value in an anchor element opens the user's email application with the specified email address.

## Tasks
1. Create about-me.html with a header containing an h1 heading with your name and a nav with two links: About pointing to #about and Contact pointing to #contact. Add an empty main and an empty footer.
2. Add a section inside main with the id about. Include an h2 heading About me and one paragraph describing yourself.
3. Add a paragraph inside the footer containing a clickable email address using mailto: in the href. Give the footer the id contact.

## Conclusion
This assignment demonstrates how semantic HTML elements organize a personal webpage. It also explains internal navigation links and how to create clickable email links using mailto.
